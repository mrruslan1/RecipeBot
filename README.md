_📋 Кулинарный бот «Вкусновик»_
>Над ботом работали Сологуб Руслан и Марков Святослав(@Lazerdimtert_bot)

**Бот помогает найти рецепты блюд по ингредиентам и предлагает случайные идеи для ужина. Работает через открытый API Themealdb.com.**

_⚙️ Как работает_
Нажмите на кнопки интерфейса, чтобы получить случайное блюдо из базы данных.
Напишите название продукта или блюда (например: «курица», «пицца», «картофель») — бот покажет список подходящих рецептов.
Нажмите на кнопку под сообщением, чтобы увидеть полный список ингредиентов и ссылку на подробный рецепт.
>Важно: Бот не хранит ваши сообщения и не собирает данные о вас.

_🛠 Запуск локально_
Установите Python 3.x.
Создайте виртуальное окружение:
bash
Копировать
python -m venv venv
Активируйте его:
Windows: venv\Scripts\activate
Linux/MacOS: source venv/bin/activate
Установите зависимости:
bash
Копировать
pip install pyTelegramBotAPI requests
Получите токен у @BotFather в Telegram.
Скопируйте файл bot.py в папку проекта и замените <ТВОЙ_ТОКЕН> на ваш реальный токен.
Запустите:
bash
Копировать
python bot.py
Найдите своего бота в Телеграме и отправьте ему сообщение!
